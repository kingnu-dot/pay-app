# verify（pay-app：公開リポジトリ）

以下を**上から順に**実行する。どれかが失敗したら、そこで止めて原因と直し方を報告する（勝手にテストを書き換えて通さない）。

1. **テスト**：`npm test`
   - 判定ロジックの単体テストがすべて通ること
2. **型チェック・lint**：`npm run lint`
3. **ビルド**：`npm run build`
   - 生成物のサイズを前回と比べ、大きく増えていたら報告する（軽量を保つため）
4. **漏洩チェック**：`node "$HOME/.claude/hooks/leak-check.mjs" --manual .`
   - 禁止語が見つかったら、架空の名前に置き換える案を出す（私の承認後に修正）
5. **差分の目視確認**：`git diff --cached --stat` と `git status` を見て、
   - 意図しないファイル（`.env`、トークン、個人データ、`../pay-rules` からのコピー）が含まれていないか確認する

## 報告の形式
- 各ステップを「OK / NG」で一覧にする
- NG があれば、ファイル名・行番号・原因・直し方を書く
- すべて OK なら、commit メッセージの案を1行で出す（実在のカード名・店名を含めない）
